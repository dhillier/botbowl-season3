# Season 3 migration coverage

Status: incomplete preview, 28 October 2026. Rules identifier `BB2025`; configuration `season3-preview`. Five implementation slices of the fixed-Human, standalone-match scope in [BUILD_PLAN.md](../BUILD_PLAN.md) are complete: characteristics/ball resolution, Secure the Ball, declared Blitz targets/jumping, stalling/status/starting-skill interactions, and selected-roster kick-off/weather/injury/drive flow.

The ordinary configurations, web default, and registered Gym environments still select BB2016. The preview must be requested explicitly. Its configuration name, serialized game status, and example launcher all identify it as incomplete. A completed preview match establishes integration stability, not complete rules fidelity or bot strength.

| Characteristics | AG and PA use native targets; AV uses the armour target. Edition-independent target accessors update resolution, action previews, and probability helpers. PA and the profile format are serialized; passing rolls have a separate roll type. Native characteristic limits are represented; progression and persistent casualty effects remain excluded. |
| Passing | Ball passes test PA before interception. Pass and team re-rolls resolve before flight. Quick/short/long/bomb modifiers are 0/-1/-2/-3, with existing marking/weather penalties. Natural 1 fails and natural 6 succeeds. Fumbles bounce from the passer and cause a turnover; inaccurate passes scatter three times before determining the interception path. |
| Interception | Eligible players are selected using the actual landing square. Accurate passes impose -3; inaccurate passes -2, plus marking/rain. Catch does not re-roll an interception. Only the active team may use team re-rolls. Existing flight-line geometry is retained; a precise ruler/geometry audit is still pending. |
| Landing/catching | Accurate, inaccurate, hand-off, and kick catches have no base modifier; bounce/throw-in catches have -1. Existing marking/rain penalties apply. Catch still re-rolls catches. A pass landing on the ground or an opposing carrier causes turnover after resolution; a friendly recovery can preserve the turn. A fumble causes turnover even if recovered. |
| Team re-rolls | More than one may be spent in the same team turn on distinct tests. Neither a skill nor team re-roll can re-roll an already re-rolled test. Existing BB2016 configurations retain their one-team-re-roll limit. |
| Secure the Ball | Once per normal team turn, spent at declaration even when a pre-action trait fails. Requires a reachable loose ground ball more than two squares from every standing, non-Distracted opponent (diagonals count). Big Guy/No Hands players are excluded. Uses normal movement, standing, dodge and rush risks, then a fixed 2+ roll unaffected by AG, weather or Sure Hands. Team re-rolls are allowed, once per test. Success ends activation; failure bounces and turns over. Ending movement short of the ball also turns over. Starting on a loose ball, prone starts, turn reset and scoring are covered. |
| Declared Blitz target | Starting a Blitz opens a target declaration owned by the active coach. Only reachable standing opponents are offered; reachability accounts for standing up, Rushes, jumps and continuing after a successful pickup, and reserves movement for the Block. The target is chosen before activation traits roll. The Blitz allowance is consumed even if the player fails a trait or declines the Block. Undo cannot restore it. Subsequent Block choices/pathfinding are restricted to that target, and the target is exposed in the existing highlight/feature layer. Movement can continue after the Block. |
| Jumping over players | Any selected roster player can jump over adjacent prone/stunned players into eligible empty squares, following both supplied diagrams. A jump costs two movement points. Any required Rushes occur first and fail at take-off. The jump tests AG with the worse of take-off/landing marking, without a Dodge skill re-roll. A natural 1 falls at take-off; another failed jump falls at landing. Success can continue movement, recover a ball, score, or finish Secure the Ball. Team re-rolls and repeated jumps are supported. |
| Stalling and Forego Activation | At activation start, snapshot whether the carrier can score within MA along an empty route without Dodge, Rush, jump, Block or an activation-trait roll. If they finish without scoring, roll against the current turn number; a hit knocks them down with normal armour/ball resolution and causes turnover. No team re-roll is offered. Natural 1 can hit on turn 1; natural 6 cannot hit on turns 7–8. Passing/handing off and ending without the ball is exempt; merely declaring either action is not. Picking up or moving into range during activation does not create stalling. Ending the team turn before activating a carrier is exempt. Forego is a separate legal choice that consumes that player’s opportunity without clearing Distracted or triggering activation traits, but still checks stalling. Season 3 activation declarations cannot be undone to clear a status for free. |
| Stunned recovery | Snapshot the team’s stunned players at the start of its normal turn. They remain stunned and cannot activate throughout that turn, then become prone when it ends, including turnovers. Players stunned during their own turn wait until the end of their next own turn; opponent turns and kickoff bonus turns do not recover them. |
| Human starting skills | Block, Dodge, Tackle, Catch, Pass and Sure Hands require Standing/non-Distracted status. Skill possession remains distinct from current availability. Dodge’s once-per-turn movement re-roll remains separate from its repeatable protection against Stumble. Distracted/prone Tackle cannot suppress Dodge; active Tackle prevents the re-roll without consuming it for later use. Both pathfinders now model Tackle on marked departures. The Season 3 one-die block probability helper also accounts for the defender’s Block on Both Down. |
| Fans and kick-off table | Prepared roster fans map to Dedicated Fans (3), plus D3 Fair-weather Fans for game Fan Factor; legacy FAME is not used. All eleven 2D6 entries use the supplied Season 3 table: Get the Ref, TIME-OUT, Solid Defence, High Kick, Cheering Fans, Brilliant Coaching, Changing Weather, Quick Snap, Charge, Dodgy Snack and Pitch Invasion. TIME-OUT uses the kicking marker, changes actual remaining turns, and needs no extra die. Cheering Fans adds an offensive assist to the first performed Block next normal turn, including a Blitz Block and its re-roll, then expires. Brilliant Coaching grants a tracked drive-only re-roll, spent before ordinary re-rolls. Dodgy Snack selects the losing side(s), applies temporary MA/AV reductions or removes a player for the drive. Pitch Invasion uses Fan Factor and selects D3 distinct players on the losing side(s) to become prone/stunned. |
| Limited kick-off movement | Solid Defence selects up to D3+3 initially Open players before removing/re-setting them, with no substitutions or changes to unselected players. Quick Snap and Charge also select their full eligible group before moving. Quick Snap moves each selected player at most one free square, can cross halfway, and does not activate traits or clear Distracted. Charge permits normal movement and one declared-target Blitz, allows applicable re-rolls, and ends on a selected active player falling/being knocked down. No Throw/Kick Team-mate players are present. The ball remains airborne until the event finishes. Touchback placement is the receiving coach’s decision, including an empty-square choice when no player is standing. |
| Weather | The five weather-table ranges and Sunny PA, Rain pickup/catch/interception, and Blizzard Rush/pass-range effects are checked. Changing Weather to Perfect Conditions always scatters the airborne kick three squares, including when the preceding weather was different; it cannot catch en route. Sweltering Heat rolls one shared D3 at drive end and randomly excludes that many on-pitch players from each team for the next drive, capped by availability. Exclusions last exactly one drive and do not affect the previous drive’s bench. |
| Injury and treatment | The fixed roster retains the standard 2D6 injury ranges (2–7 stun, 8–9 KO, 10–12 casualty), with crowd stuns returning to reserves. Casualties use D16 and the five Season 3 classifications; all remove the player for this standalone game. Persistent injuries, the Lasting Injury subtable and league after-effects are excluded. Although the prepared roster has no Apothecary, shared treatment now uses D16 and can return a patched-up Badly Hurt player to reserves; KO treatment stuns on the pitch or returns a crowd victim to reserves. ## Interpretation that needs coach review

The supplied revised fumble wording says a natural 1 or a result of **exactly 1 after modifiers**. The general dice revision strikes out the lower bound on modified rolls, retaining only an upper cap of 6. Taken together, a natural 2 with a -3 passing modifier produces -1 and is an inaccurate pass; a natural 4 with that modifier produces 1 and is a fumble. A natural 6 still succeeds.

The preview follows that literal wording, rather than the upstream `modified <= 1` rule. All six long-bomb results are tested so this interpretation is visible and easy to change if the supplied document is clarified. This decision is based on visually checking the revised pages, not only PDF text extraction.

## Running and verifying

From the repository root, with dependencies installed:

```sh
python setup.py build_ext --inplace
python scripts/build_web_js.py --check
python -m pytest tests/game/test_season3.py tests/game/test_secure_ball.py tests/game/test_season3_actions.py tests/game/test_season3_status.py tests/game/test_season3_flow.py -q
python -m pytest -q
python -m examples.season3_preview --seed 0
```

The first command builds the optional Cython pathfinder. When it is unavailable, the engine falls back to Python and the tests explicitly skip compiled-only cases. Rebuild after changing `.pyx` sources. The example loads the preview configuration and two fresh fixed Human teams, then plays a full match between the existing scripted bots.

The web page serves `static/dist/js/botbowl.js`, not the individual source files. After editing `botbowl/web/static/js/*.js`, run `python scripts/build_web_js.py` and commit the generated bundle too. This standard-library script reproduces the existing Gulp concatenation task without requiring its old Node dependencies. `--check` detects stale output.

Development environment verified on this Mac: Apple Python 3.9.6 in `.venv`, the upstream `requirements.txt`, and a local override `urllib3==1.26.20`. The upstream urllib3 2.0.2 pin cannot import with this Apple Python's LibreSSL. To reproduce this specific environment after installing requirements, run `python -m pip install urllib3==1.26.20`. This is a recorded local compatibility workaround; dependency modernization and Windows/5090 validation remain separate work. The full upstream suite emits existing Gym observation/deprecation warnings; a passing suite does not certify those interfaces for Season 3 training.
