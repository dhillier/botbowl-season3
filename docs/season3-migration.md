## Approved interpretation

The supplied revised fumble wording says a natural 1 or a result of **exactly 1 after modifiers**. The May 2026 FAQ allows modified results below 1 but does not resolve that wording. On 28 October 2026 the user chose **modified 1 or less as a fumble on a failed Passing Ability Test**. On 31 October the user relayed the explicit exception: **PA 1+ succeeds on a modified 1 unless the die is a natural 1**. Natural 1 still fails and natural 6 still succeeds. The engine already checks success before classifying a fumble.

With only a Long Bomb's -3 modifier, the original **PA 4+** example fumbles on natural 1–4, is inaccurate on 5 and accurate on 6. A **PA 1+** passer instead fumbles on natural 1–3 and passes accurately on 4–6.

The preview follows that approved project ruling and user-relayed clarification. Tests enumerate all natural results across range, sun and marking penalties, explicitly cover PA 1+/PA 2+ boundaries, and verify Pass/team re-roll timing. This is not presented as an official erratum. The [acceptance record](season3-acceptance.md) records the source distinction and the digital ruler convention.

## Running and verifying

```sh
python setup.py build_ext --inplace
python scripts/build_web_js.py --check
python -m pytest tests/game/test_season3.py tests/game/test_secure_ball.py tests/game/test_season3_actions.py tests/game/test_season3_status.py tests/game/test_season3_flow.py tests/game/test_season3_ball.py tests/game/test_season3_pathfinding.py tests/game/test_season3_geometry.py tests/game/test_season3_acceptance.py -q

python -m pytest -q
python -m examples.season3_preview --seed 0
```

The first command builds the optional Cython pathfinder. When it is unavailable, the engine falls back to Python and the tests explicitly skip compiled-only cases. Rebuild after changing `.pyx` sources. The example loads the preview configuration and two fresh fixed Human teams, then plays a full match between the existing scripted bots.

The web page serves `static/dist/js/botbowl.js`, not the individual source files. After editing `botbowl/web/static/js/*.js`, run `python scripts/build_web_js.py` and commit the generated bundle too. This standard-library script reproduces the existing Gulp concatenation task without requiring its old Node dependencies. `--check` detects stale output.
